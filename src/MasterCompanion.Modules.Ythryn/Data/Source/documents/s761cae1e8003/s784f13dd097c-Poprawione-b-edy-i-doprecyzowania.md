| Miejsce | Poprawka |
| --- | --- |
| **Y1** | „Faceless” oznacza **bez twarzy**, nie „bezimienny”. Przywrócono też pozycję posągu leżącego twarzą do ziemi. |
| **Y3** | Bariera zadaje **40 (9k8)** obrażeń przy pierwszym dotknięciu w **danej turze**, także cudzej. Wcześniejsze „w swojej turze” zawężało zasadę. |
| **Y3** | Informacje o odgałęzieniach trójzębów odnoszą się do odgałęzień, a nie do wysokości całych masztów. Utrudnienie za nieznajomość gry dotyczy testów umiejętności. |
| **Y7** | Figurkę opisano jako **królika**; wisior przedstawia **wronią łapę**, nie kurzą. Wartości pozostały zgodne ze źródłem. |
| **Y9** | Kingsport jest w opisie **pozbawiony oczu**, a nie jedynie niewidzący. Poprawiono też sformułowanie o wycofaniu się Scrivenscry przy przewadze przeciwników. |
| **Y10** | Needle blights działają przy **tej samej wartości inicjatywy co dąb**. |
| **Y13** | Bezgłowy golem jest **blinded i deafened**, nie stunned. „Ogłuszony” zastąpiono jednoznacznym „ogłuchły (deafened)”. |
| **Y16** | Dopisano polecenie rzutu **k6** na stworzenie. Koszt 80 PW krwi zapisano także jako 10 PW na każdy z ośmiu pojemników. |
| **Y19b, Y19f, Y19m** | Doprecyzowano maski trzymane na rączkach, półprzezroczyste szkło trzeciego kostura oraz złowróżbne poczucie zagłady związane z gwiazdą. |
| **Y20** | Usunięto dodany przymiotnik „okrągła”: sala jest **ośmiokątna**, o średnicy 30 stóp. |
| **Y22** | „Illusory script” w tym akapicie jest opisem iluzorycznego napisu; usunięto kursywę sugerującą nazwę konkretnego zaklęcia. |
| **Y24** | Zaznaczono, że ograniczenie zdejmowania korony dotyczy **samego noszącego**; inna osoba może ją zdjąć. Stan Iviry oznaczono jako **stunned**. |
| **Y29** | Przywrócono wzmiankę o schodach na górny poziom. |
| **Bractwo i epilog** | Avarice określono jako albinotyczną **tieflinkę**. Poprawiono odniesienia do dwóch czarodziejek oraz polskie nazwy kruka i reniferów. |
