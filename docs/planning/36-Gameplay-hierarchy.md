# Gameplay intent and information hierarchy

6 October 2026 · slice D

Compared persistent section navigation with collapsible task groups using the
same encounter/rival/character fixture. Native details groups reduce initial
screen density and preserve mounted input owners. The attention summary stays
outside the groups; its buttons expand ancestors and focus their actual targets.
Each group retains its open state across workspace tabs and shows pending counts.

```text
Clock / reachable undo -> choose advance or rest -> review effect -> apply
Attention summary -> named action -> open task group and focus target
Encounters and arrivals | Arcane Blight | Rival forces
```

The engine owns advance/rest selection and the sticky page command area. Choosing
an activity submits no operation. The selected form states its clock/exploration
effect before the explicit apply action. The module owns exploration/search
effects, disclosures of detailed rules, attention counts and rival/character
consequences. Arrival submission names its target and reviews entered elapsed
time and encounter replacement effects; Auril conversion is explained at the
submission point. A third failed recovery identifies the character and resulting
transformation before the failure button. Existing rules, transactions, receipts
and undo are unchanged; no engine branch interprets Ythryn state.
